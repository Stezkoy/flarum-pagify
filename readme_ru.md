# Pagify

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/stezkoy/flarum-pagify.svg)](https://packagist.org/packages/stezkoy/flarum-pagify) [![Total Downloads](https://img.shields.io/packagist/dt/stezkoy/flarum-pagify.svg)](https://packagist.org/packages/stezkoy/flarum-pagify)

Расширение для Flarum, которое заменяет «Показать ещё» и бесконечную прокрутку на нумерованные страницы для списка тем и потока постов.

[English version](readme.md)

## Возможности

### Пагинация списка тем
Заменяет кнопку «Показать ещё» на главной на нумерованный пейджер.
- Настраиваемое количество **тем на страницу**
- Позиция пейджера — **сверху**, **снизу** или **сверху и снизу**
- Быстрый переход к странице через **поле ввода номера страницы** (введите число и нажмите Enter или кнопку перехода)

### Пагинация потока постов
Заменяет бесконечную прокрутку внутри темы на нумерованные страницы.
- Настраиваемое количество **постов на страницу**
- Позиция пейджера — **сверху**, **снизу** или **сверху и снизу**
- **Количество постов на страницу применяется только при включённой пагинации постов** — когда она выключена, посты грузятся стандартным способом Flarum

### Гибкое количество на страницу
- **Тем на страницу** работает и при выключенной пагинации списка: определяет размер блока кнопки «Показать ещё».
- При включённой пагинации пейджер появляется сразу, не затрагивая основной список тем.

## Установка

```bash
composer require stezkoy/flarum-pagify
```

## Требования

- Flarum 2.0
- PHP 8.3+

## Настройка

Все настройки — в **Админ > Расширения > Pagify**. Каждую функцию можно включить/выключить независимо:

- **Пагинация списка тем** — нумерованные страницы на главной
- **Тем на страницу** — размер страницы списка (а также размер блока «Показать ещё», если пагинация выключена)
- **Позиция пагинации** — где показывать пейджер списка (сверху / снизу / сверху и снизу)
- **Пагинация постов внутри темы** — нумерованные страницы в потоке постов
- **Постов на страницу** — размер страницы внутри темы (только при включённой пагинации постов)
- **Позиция пагинации постов** — где показывать пейджер постов (сверху / снизу / сверху и снизу)
